# 🔐 Password Strength Checker

## 📌 Overview

This project is a Python-based tool that evaluates the strength of a password based on common security rules.
It analyzes user input and classifies the password as Weak, Medium, or Strong.

## ⚙️ Features

* Checks minimum password length
* Detects uppercase and lowercase letters
* Identifies numbers and special characters

## 🧠 How It Works

The program takes a password as input and applies multiple validation checks.
Each condition contributes to classify the password strength.

## ▶️ Example

Input: Pass12345!
Output: Strong Password
